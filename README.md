# MOVORA — Movie & TV Discovery Platform

MOVORA is a modern movie and TV show discovery platform built with React. Inspired by popular streaming platforms, it features a cinematic interface that makes exploring movies and television shows simple and engaging.

## ✨ Features

- **Home Page** — Explore featured content and curated collections.
- **Movie Discovery** — Browse movies across different categories.
- **TV Shows** — Discover popular and curated television shows.
- **Search** — Find movies and TV shows.
- **Details Pages** — Explore detailed information about movies and TV shows.
- **My List** — Save and manage your favorite titles.
- **Kids Section** — Dedicated section for kids' content.
- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

- React
- Vite
- JavaScript (ES6+)
- Tailwind CSS v4
- React Router
- Lucide React
- Browser Local Storage


## 🔑 API Configuration

MOVORA is planned to use the [TMDB API](https://www.themoviedb.org/documentation/api) for movie and TV show data.

When API integration is configured, add the required credentials to a local `.env` file. Never commit API credentials to the repository.

## 🚧 Project Status

MOVORA is currently under active development.

The current version focuses on the frontend experience, curated movie and TV show catalog, navigation, responsive UI, and watchlist functionality.

Upcoming development includes TMDB API integration and additional streaming-platform features.

**Note:** Full movie and TV episode playback is not currently implemented.
